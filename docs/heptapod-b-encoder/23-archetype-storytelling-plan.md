# 24유형 스토리텔링 강화 계획

작성일: 2026-09-07. 상태: 24유형 한영 원고 작성·기존 설명 영역 연결·최종 검사 완료. 최초 계획 이후 사용자의 연속 진행 요청에 따라 콘텐츠 적용까지 수행했다.

## 1. 목표와 범위

현재 세계관과 Archive의 배포된 24유형에, 사용자가 자기 표식의 유형을 기억하고 설명할 수 있는 정체성·특징·서사를 부여한다. MBTI에서 참고할 표현 방식은 기억하기 쉬운 유형명, 일정한 설명 구조, 유형별 차이, 다른 유형과 비교하며 이해하는 재미다.

이번 산출물은 세계관 설정과 유형별 콘텐츠 원고다. 페이지 구성, 탭, 카드, 네비게이션, 분석 인터랙션, 공유 기능, 애니메이션을 설계하는 작업은 포함하지 않는다. 이름으로 실제 성격을 판정하는 체계로 바꾸지 않는다. 사용자가 이 세계에서 자신의 표식을 하나의 역할로 받아들이도록 쓴다.

기존 유형명 24개와 상위 군집명은 유지한다. 분류 키·형태 판독·임계값·소속·공개 데이터도 유지한다. 서사 표현을 강화하기 위해 사용자의 유형을 재배정하지 않는다.

## 2. 현재 확인된 체계

확인 근거:
- `src/data/heptapodMeaningCatalog.js`: 도래(arrival), 수용(reception), 상호성(reciprocity).
- `src/utils/heptapod/interpretGlyphMeaning.js`: 동시성(simultaneity), 여백(openness), 잔향(trace)의 true/false/null 판독.
- `src/data/heptapodArchetypeCatalog.js`: 상위 군집 3개 × 메타데이터 8조합의 24개 정확한 유형 키. 집필 전 narrativeVersion=1, 이번 원고는 2.
- `src/i18n/locales/archetypes.js`: 유형별 한영 제목과 짧은 reading.
- `src/data/heptapodHeroStory.js`, 한국어 원문: 한 번에 그려지는 원, 함께 존재하는 먼저와 나중, 이름의 응축, 다른 존재에게 건네는 응답.
- `docs/heptapod-b-encoder/19-archetype-feed.md`: 정확한 조합으로 한 유형에 소속되는 기존 계약.

현재 부족한 부분은 유형 수가 아니라 설명의 깊이다. 한 줄 reading만으로는 같은 군집 안에서 메타데이터 하나가 달라졌을 때 무엇이 달라지는지, 세 속성이 함께 있을 때 어떤 독립된 역할이 생기는지 충분히 드러나지 않는다.

## 3. 조합을 빠짐없이 다루는 규칙

현재 메타데이터의 수 n은 3이다. 동시에 1개, 2개, 3개가 나타나는 경우를 모두 쓰고, 기존 카탈로그에 있는 0개 조합도 포함한다.

| 활성 메타데이터 수 | 군집당 조합 | 전체 유형 수 |
|---|---:|---:|
| 0개 | 1 | 3 |
| 1개 | 3 | 9 |
| 2개 | 3 | 9 |
| 3개 | 1 | 3 |
| 합계 | 8 | 24 |

전체 경우의 수는 `3 × Σ C(3,k), k=0…3 = 3 × 2³ = 24`다. 메타데이터가 하나 이상인 유형은 21개이며 기본형 3개를 더한다. 향후 실제 판독 메타데이터가 n개로 늘면 이론적인 집필 범위는 `3 × 2ⁿ`이 되지만 이번에는 기존 3개만 사용한다.

- 동시성+여백이 확인된 표식에는 해당 복합 유형 하나의 원고를 적용한다. 동시성 단독·여백 단독 원고를 중복 적용하지 않는다.
- 복합 유형 원고 안에서 활성 메타데이터 각각과 결합 효과를 모두 설명한다.
- 0개 조합은 세 추가 속성이 모두 false로 확인된 기본형이다. 특징이 없는 유형으로 취급하지 않는다.
- null/미확인은 false가 아니다. 기존 partial/invalid 상태를 24개 중 하나로 강제하지 않는다.
- 메타데이터 수는 서사의 복합성을 뜻하며 강함·희귀함·진화 단계·우수함을 뜻하지 않는다.
- 24개 원고의 완성과 실제 인코더에서 24개가 모두 생성되는지는 별개의 사실이다. 현재 DB 출현 빈도나 인코더 도달성을 집필만으로 주장하지 않는다.

## 4. 세계관의 공통 문장과 서사 문법

집필 기준 문장 제안:

> 당신의 이름은 하나의 응답이 됩니다. 유형은 그 응답이 세계를 향하는 방향과, 시간·경계·흔적을 다루는 방식을 이야기합니다.

서사의 주체는 표식과 그 표식이 맡는 세계 속 역할이다. 이름의 어원, 지능, 실제 성격, 운명을 추정하는 문장은 쓰지 않는다. 모든 원고에서 영화의 문법을 확장한 프로젝트 고유 해석이라는 태도를 유지한다.

### 세 상위 군집: 응답의 방향

| 군집 | 서사의 중심 행동 | 세계 속 역할 | 반복해서 탐구할 질문 |
|---|---|---|---|
| 도래 | 건넨다 | 아직 응답이 시작되지 않은 곳에 신호를 보낸다 | 무엇을 먼저 건넬 것인가? |
| 수용 | 받아 담는다 | 도착한 신호가 머물고 뜻을 얻을 자리를 만든다 | 무엇을 안에 남길 것인가? |
| 상호성 | 주고받는다 | 받은 신호를 다음 응답으로 돌려보내며 관계를 이어 간다 | 주고받은 뒤 무엇이 달라지는가? |

수용을 수동적 유형으로, 도래를 우월한 리더로, 상호성을 둘의 상위 버전으로 서술하지 않는다. 세 역할 모두 세계의 응답을 성립시키는 독립된 기능을 갖는다.

### 세 메타데이터: 역할을 바꾸는 조건

| 메타데이터 | 서사에서 담당하는 것 | 반드시 설명할 변화 |
|---|---|---|
| 동시성 | 서로 떨어진 순간의 공존 | 먼저와 나중의 신호를 함께 건네거나, 품거나, 주고받을 때 생기는 변화 |
| 여백 | 아직 채워지지 않은 경계 | 다른 응답이 들어오거나 건너갈 자리가 있을 때 생기는 변화 |
| 잔향 | 여러 곳에 남는 흔적 | 만남 이후에도 흔적이 남아 다음 응답에 작용하는 방식 |

false에 대한 집필 규칙:
- 동시성 false를 선형 시간만 이해한다는 성격으로 바꾸지 않는다. 전체 세계관의 비선형 시간과 충돌하지 않도록 동시성이 강조되지 않은 응답으로 다룬다.
- 여백 false를 폐쇄적 성격이나 타인 거부로 바꾸지 않는다. 원의 닫힌 형태와 내향성은 같은 뜻이 아니다.
- 잔향 false를 기억이 없거나 공감하지 못한다는 뜻으로 바꾸지 않는다. 여러 잉크 봉우리가 관측되지 않았다는 사실을 성격 결핍으로 확대하지 않는다.

### 복합 서사의 결합 규칙

| 조합 | 독립적으로 집필할 주제 |
|---|---|
| 없음 | 해당 군집의 중심 행동을 가장 또렷하게 드러내는 응답 |
| 동시성 | 떨어진 순간이 함께 놓일 때의 응답 |
| 여백 | 완성하지 않은 경계를 통해 이어지는 응답 |
| 잔향 | 만남 이후 남아 작용하는 응답 |
| 동시성+여백 | 서로 다른 순간이 드나들 자리를 만드는 응답 |
| 동시성+잔향 | 떨어진 순간의 흔적이 서로의 맥락이 되는 응답 |
| 여백+잔향 | 남은 흔적이 다음 존재가 들어올 자리를 만드는 응답 |
| 동시성+여백+잔향 | 앞선 흔적과 아직 오지 않은 응답이 열린 경계를 통해 함께 작용하는 응답 |

단일 메타데이터 설명의 나열은 집필 완료로 인정하지 않는다. 결합한 결과 역할·장면·긴장 중 무엇이 달라지는지 한 문장으로 설명할 수 있어야 한다.

유형명은 배포된 이름이다. 마지막 열은 이번 집필을 위한 제안이며 아직 서비스에 반영한 원고가 아니다.

## 6. 유형별 원고의 공통 구조

24유형 모두 다음 10항목을 채운다. 항목은 콘텐츠 원고의 구조이며, 화면에 새 섹션 10개를 만들겠다는 설계가 아니다.

| 항목 | 분량 기준 | 작성 내용 |
|---|---|---|
| 기존 유형명 | 유지 | 이미 공유·배포된 정체성 |
| 정체성 한 문장 | 1문장 | 이 표식이 세계에서 맡는 고유 역할 |
| 핵심 서사 | 180~260자 | 조합이 실제로 작용하는 한 장면. 한 줄 reading의 확장 원문 |
| 대표 특징 | 3개, 각 1~2문장 | 신호를 건네거나 받는 방식, 시간·경계·흔적을 다루는 방식, 남기는 변화 |
| 빛나는 순간 | 2개, 각 1문장 | 이 역할이 의미를 얻는 구체적 상황 |
| 긴장과 대가 | 1~2문장 | 강점과 같은 근원에서 생기는 서사적 갈등 |
| 다음 응답의 질문 | 1개 | 유형을 우열로 평가하지 않고 자기 해석을 넓히는 질문 |
| 다른 유형과의 서사 | 2개, 각 1~2문장 | 같은 조합의 다른 군집 1개, 메타데이터 하나가 다른 같은 군집 1개 |
| 결정적인 차이 | 1~2문장 | 가장 비슷해 보이는 유형과의 구별점 |
| 유형의 한마디 | 1문장 | 사용자가 자신의 표식에 붙여 기억할 수 있는 1인칭 문장 |

별도로 편집용 근거표를 남긴다. 각 문장이 상위 군집, 단일 메타데이터, 복합 효과 중 어디에서 나왔는지 표시한다. 이 근거표는 제품에 표시할 기술 설명이 아니다.

긴 원고에서 기존 한 줄 reading과 짧은 공유 문장을 파생해 용어와 정체성을 일치시킨다. 현재 공유 기능이나 화면 구조의 변경은 계획하지 않는다.

## 7. 문체와 깊이 예시

아래는 방향을 판단하기 위한 초안이다. 24유형 전체 원고가 완성됐다는 의미는 아니다.

### 끝과 시작의 매개자 · 상호성 × 동시성 × 여백 × 잔향

정체성: 한 응답의 끝을 다른 순간의 첫 말로 이어 주는 표식.

핵심 서사:

> 오래전에 끝났다고 여긴 대답이, 아직 도착하지 않은 질문 옆에 놓입니다. 이 표식은 둘 사이에 통로를 남깁니다. 건네받은 말은 그대로 되돌아가지 않습니다. 다른 순간에 남은 흔적과 만나 새로운 응답이 됩니다. 원 안에서 끝과 시작은 서로 자리를 바꾸지만, 목소리들은 각자의 여운을 간직합니다. 당신의 표식은 그 오가는 말들이 다시 만날 경계를 열어 둡니다.

대표 특징:
- 이어지는 응답: 받은 말이 다음 질문으로 바뀌어 돌아오도록 연결한다.
- 함께 놓인 순간: 앞선 흔적과 아직 오지 않은 응답을 한 이야기 안에서 다룬다.
- 남겨 둔 통로: 만남이 끝난 뒤에도 다른 목소리가 이어 들어올 여백을 둔다.

빛나는 순간: 끝난 대화의 흔적이 다른 순간의 질문과 만날 때. 서로의 말이 어디서 시작됐는지 알 수 없어도 다음 응답을 건넬 때.

긴장과 대가: 여러 목소리를 잇는 동안 처음의 말이 누구에게서 왔는지 경계가 흐려진다. 계속 이어지는 응답 안에서도 각각의 여운을 남겨야 한다.

다음 응답의 질문: 모든 말을 잇는 동안, 어떤 목소리는 그 자체로 남겨 두어야 할까요?

결정적인 차이: 같은 세 메타데이터를 가진 ‘시간 너머의 전령’은 신호를 바깥으로 전달하고, ‘시간을 품는 그릇’은 도착한 여운이 머무를 자리를 만든다. ‘끝과 시작의 매개자’의 중심은 주고받은 신호가 다음 응답으로 이어지는 데 있다.

유형의 한마디: “내가 건넨 답이 누군가의 첫 문장이 됩니다.”

같은 군집의 가까운 유형과 비교: ‘순간을 잇는 문’도 서로 다른 순간이 드나들 통로를 연다. 여기에 잔향이 더해진 ‘끝과 시작의 매개자’에서는 교환이 끝난 뒤 남은 흔적이 다음 교환을 다시 시작시키는 역할까지 서사에 포함한다.

## 8. 집필 순서와 산출물

1. 공통 설정 확정: 세계관 기준 문장 1개, 군집 설정 3개, 메타데이터 해석 3개, 복합 주제 8개를 정리한다. 현재 유형명과 키에 연결한 집필표를 만든다.
2. 24유형 초고 작성: 도래·수용·상호성 각각 8개를 모두 작성한다. 0개 기본형 → 단일 3개 → 이중 3개 → 삼중 1개 순으로 의미 차이를 쌓는다. 산출물은 24 × 10항목의 한국어 원고와 편집용 근거표다.
3. 유형 간 차이 검수: 같은 군집에서 메타데이터 하나만 바뀌는 36쌍, 같은 조합에서 군집만 바뀌는 24쌍을 대조한다. 총 60쌍은 차이를 검수하는 편집 기준이며 궁합 점수표가 아니다. 서로의 이름만 바꿔 붙여도 성립하는 원고는 다시 쓴다.
4. 문체·문장 정제: 구체적 장면, 강점과 같은 근원의 긴장, 기억에 남는 한마디를 점검한다. 한 줄 reading과 짧은 공유 원고도 같은 원문에서 정리한다.
5. 한영 일치본 작성: 한국어 전체 원고를 기준으로 기존 영어 유형명을 유지하며 영어판을 작성한다. 길이보다 역할·관계·정서의 일치를 우선한다.
6. 반영 명세 정리: 기존 24개 meaningKey에 최종 원고를 연결한 데이터와 변경 전후 문구표를 준비한다. 후속 콘텐츠 적용 시 narrativeVersion만 올릴 수 있도록 정리한다. 이후 연속 진행 요청에 따라 기존 문구 슬롯에 적용한다. UI 구조·분류·DB는 유지한다.

## 9. 완료 기준

- 3개 군집에 각 8개, 총 24개 원고가 빠짐없이 존재한다.
- 메타데이터 개수별 3/9/9/3 유형이 모두 포함된다.
- 모든 복합 유형에서 활성 속성과 결합 결과를 설명할 수 있다.
- 기본형을 결핍, 삼중형을 완전체로 묘사하지 않는다.
- 60개 대비 검수에서 각 조합과 방향의 차이를 구체적으로 말할 수 있다.
- 표현을 바꿔 끼워도 구분되지 않는 일반적인 칭찬, 성격 단정, 근거 없는 희귀도·궁합·순위를 포함하지 않는다.
- null/부분 판독의 기존 처리를 유지한다.
- 기존 유형명·소속·링크·분류 키와 일치한다.
- 각 원고의 장문·한 줄 요약·한영 표현이 같은 역할을 말한다.

이 계획의 최종 산출물은 24유형의 서사 사전이다. 화면 배치나 인터랙션 제안 없이도 이후 기존 설명 문구의 밀도를 높이는 데 사용할 수 있어야 한다.
