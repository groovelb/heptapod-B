# 모바일 대응 · 실행 계약

## 범위와 완료 조건

PC 배치와 타이밍을 유지하고 기존 md(900px) 미만에서만 모바일 동작을 보완한다. 랜딩 스크롤 타이밍, 실제 영상 종료 후 Canvas 전환, Enter 확정 후 키보드 종료, 전체 체험의 작은 화면/가로 화면 대응이 대상이다. 영상 완료를 타이머로 위조하거나 분석·메타데이터·공유 기능을 제거하지 않는다.

## 병렬 실행 계획

준비 조사 → 독립 수정 → root 합류·PC 회귀 및 모바일 상태 검증. 동시성은 root 포함 4개 이내. 공유 레지스트리·문서·최종 검증은 root가 소유한다.

| 작업 | 소유 파일 | 산출물·완료 조건 | 위험 |
|---|---|---|---|
| A: 랜딩 | HeptapodHeroIntro, VideoScrubbing, 스크럽 타임라인·필요한 캡션 좌표 | 모바일 타이밍 분리, 실제 ended 이후 1회 완료, PC 기본 프로필 유지 | 모바일 주소창 높이·seek/재생 경합 |
| B: Canvas | HeptapodEncoderPage, 페이지 story·전용 모바일 helper | 유효한 Enter 제출만 blur, IME 보호, 모바일 입력/표식/메타데이터/액션 접근 가능 | 키보드 resize·가로 화면 |
| C: 읽기 전용 조사 후 공유 UI 수정 | AppGNB, PublishDialog, GlyphDetailPage, ArchiveComparePage, GlyphPairComparison | 모바일 안전영역·줄바꿈·다이얼로그 폭·손상 모델 placeholder 제한 | PC 공통 스타일 영향 |
| R: 통합 | Archive 표시·전용 회귀 테스트·문서 | 모바일 계층/그리드 가독성, 기존 PC CSS 보존, 전체 빌드·회귀 | 기존 미커밋 변경과 중첩 |

각 작업자는 자기 파일만 수정하며 기존/동시 편집을 되돌리지 않는다. 파일 범위 확대는 root와 조율한다. 실패한 분기는 검증 근거와 변경을 인계하고 root가 순차 마무리한다. 브라우저/Playwright/Chrome 자동화는 사용자 허가가 없으므로 실행하지 않는다. DB 쓰기·새 의존성·배포·commit도 범위에 포함하지 않는다.

## 검증 경계

Node, 메모리 DOM, SSR/CSSOM으로 모바일 상태 전이와 PC 불변 조건을 확인한다. 320×568, 390×844, 844×390, 900px 경계와 데스크톱을 구분한다. 실제 기기 키보드 표시·모바일 영상 디코딩·손가락 스크롤 체감은 이 검사로 보장하지 않으며 별도 실기기 확인이 필요하다.

## 적용 결과

- 모바일 타이밍은 4.85셀 `[0.65, 1, 0.8, 1, 0.65, 0.75]`, 타이틀 분산 0.3셀이다. PC 기존 6.4셀과 0.45셀·영상/카피 순서·42초 자동 재생 경계는 유지한다. svh 트랙 실측값을 영상과 캡션 시계에 맞춰 주소창 높이 변화와 회전의 불일치를 보완했다.
- 960 영상은 로컬 메타데이터상 컨테이너 47.090초, 영상 47.041667초다. 모바일에서 실패한 디코더 예열을 다시 제스처로 시도할 수 있고, seek/준비/포그라운드 복귀 후 현재 프레임부터 재생을 복구한다. 종료 이벤트 누락 복구에도 실제 `ended`·재생 위치 검증이 필수다. 타이머·마지막 프레임으로 강제 완료하지 않는다.
- Canvas의 기존 Enter는 확정만 하고 blur하지 않았다. 모바일 정상 확정 후 blur 및 form submit을 연결했다. Safari IME 229가 새 form을 암묵 제출하지 않도록 기존 preventDefault 가드를 보존했다. 모바일 메타데이터는 값 네 개를 그대로 2행(64px)에 배치하고 PC는 기존 4행(128px)이다. 분석을 켜도 각 모드의 높이는 유지된다.
- Archive 포털 모바일 2열, 600px 미만 유형 헤더 세로 배치, 공유 창/상세/비교의 작은 폭·가로 안전영역을 보완했다. 기존 모델·분류·형성·분석 효과·Lenis·공개 동의 절차는 유지한다.
- 병렬 작성 후 실행 한도로 작업자가 중단되어 root가 남은 리뷰/IME 보완/통합 검증을 순차 완료했다.

검증: 모바일 hero 27개, Canvas 36개, 공용 UI 15개, Archive CSSOM 14개 통과. Archive 검사에는 수정 전에 수집한 900/1440px PC CSS 해시 6개의 일치 검증이 포함된다. 기존 라우트 76개·영상 67개·모션 7개, 유형/공유/Archive/결과 화면 회귀, 한영 1738+21개, 공용 탐색 37개도 통과했다. 변경 컴포넌트 ESLint 통과. `check-agent-rules`는 저장소에 정의되어 있지 않아 실행 불가다. 기존 ScrambleCaption 렌더 중 상태 변경 경고 및 큰 번들/MUI 패키지 메타데이터 경고는 별도 과제로 남긴다.
