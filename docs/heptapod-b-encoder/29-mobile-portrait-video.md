# 모바일 세로 영상 적용

사용자가 8컷 전체 검토본을 모바일에 먼저 적용하고 현재 모든 세션의 코드를 commit/push하도록 요청했다.

- 모바일 영상: `/heptapod-b-encoder/hero-scrub-v2-mobile/hero-scrub-1080x1920.mp4`
- 1080×1920, 24fps, 1129프레임, 영상 길이47.041667초, GOP6.
- 검토본 `output/heptapod-mobile-portrait-v2/video-run-01/staging/hero-portrait-raw.mp4`를 재인코딩 없이 복사했다. 해시는 해당 public 폴더의 `manifest.json`에 기록한다.
- 모바일 포스터는 이 영상의 첫 프레임이다. 영상과 포스터 선택은 같은 소스 기준으로 고정되어 회전·리사이즈 도중 다른 영상 포스터가 나타나지 않는다.
- PC Topaz 영상, 비트 시간, 모바일 스크롤 길이와 로딩·재생 복구 동작은 유지한다.
- 생성 원본 높이1916/1920px 차이는 검토본 조립 당시 상하2px 검정 여백으로 맞췄다. 내용 크기 변경·색보정·광학흐름·전환 효과는 적용하지 않았다.

검토 당시 C07의 약37.8초 난간 소멸이 기록되어 있다. 사용자는 이 검토본을 먼저 적용한 뒤 영상의 어색한 점을 별도로 확인하도록 요청했다. 이 적용은 모든 시각 오류가 해결되었다는 판정을 뜻하지 않는다.

생성 작업 소스는 함께 보관하되 대용량 중간 영상·이미지·다운로드 캐시는 제외한다. 실제 배포에 필요한 영상·포스터는 `public`에 포함한다.
