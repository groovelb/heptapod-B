Visual language

레퍼런스 사이에서 이어갈 세 가지 기준.

01 / Scale

구조물은 거대하게, 인물은 작게

검은 타원형 선체와 넓은 빈 공간. 네 명의 연구자, 리프트, 장비가 공간의 크기를 드러냅니다.

02 / Material

반사보다 질감

무광 표면, 어두운 석재의 결, 절제된 필름 질감. 의복과 장비도 같은 낮은 채도의 세계 안에 둡니다.

03 / Light

차가운 확산광과 하나의 발광면

그린 그레이에서 블루 그레이로 이어지는 색감. 빛의 형태와 위치를 유지하며 밝은 막 표면으로 수렴합니다.

Preservation prompt

구도와 비율의 보존을 요청한 실제 사용 프롬프트.

Reference first

원본 이미지 한 장을 Attach to prompt로 첨부하고 아래 문장을 사용했습니다. 최종 후보는 Creation Actions → Vary → Subtle 결과에서 골랐습니다.

이미지의 고유한 형상과 인물 수를 우선하고, 선명도와 차분한 색감을 조정하는 방향입니다.
