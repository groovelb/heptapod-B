# 08 · Kinetic Typography Ideation — 스토리텔링 키네틱 타이포

> 스크럽 히어로(07)의 캡션 6개(B0~B5)를 **한 가지 모션 문법** 위에서 **비트별 변주**하는 키네틱 타이포 아이데이션.
> 통일성의 축은 "무엇이 움직이게 하는가(구동)·무엇으로 보이는가(재질)·어디에 놓이는가(격자)" 세 가지를 고정하는 것이고,
> 변주의 축은 "글자가 나타나는 순서·방향"과 "공간 변형" 두 가지만 연다. 레이아웃은 택소노미(§8 Layout)의
> Unusual 항목(BrokenGrid·DiagonalGrid·CollageLayout·OverlappingStack)을 비트 내용이 요구할 때만 차용한다.
> 선행: `03-visual-direction.md` §5.5, `06-hero-storyline.md`, `07-scroll-scrub-sound-plan.md`, `docs/taxonomy-v0.4.md` §8·§11·§14.
> 작성일: 2026-09-03 · 결정·1차 구현: 2026-09-03 (§7)

## 0. 한 줄 컨셉

> **"타이포도 스크럽된다."** 모든 글자 모션은 시간이 아니라 **스크롤 위치의 함수** — 같은 위치에서는 항상 같은 상태(가역·결정론).
> 인코더의 "같은 이름 → 같은 로고그램"과 같은 원리를 히어로 타이포에 미리 체험시킨다.

## 1. 통일 문법 (고정 — 전 비트 공통)

| 축 | 규칙 | 근거 |
|---|---|---|
| **구동** | 비트 로컬 진행도 `f = (p − startNorm) / (endNorm − startNorm)` (0~1) 하나로 모든 변형을 계산. 시간 기반 애니메이션은 B5 커서 깜빡임 하나만 예외 | 영상·사운드·타이포가 같은 손(스크롤)으로 움직인다. 멈추면 전부 멈춤 |
| **재질** | "서리 유리 위의 잉크": 등장 = `blur 12px→0 + opacity 0→1`(BlurInReveal), 퇴장 = 흩어짐(`blur↑ + letter-spacing +0.06em + opacity↓`). 슬라이드·바운스·스케일·웨이트 모핑 금지 | 03 §1.4 잉크 번짐·농담, 03 §5 빠른 스냅 금지 |
| **타이밍** | 등장 구간 f 0→0.35, 유지 0.35→0.8, 퇴장 0.8→1. 매핑 이징 `cubic-bezier(0.16, 1, 0.3, 1)` 공통 | 비트 길이(셀 가중치)가 달라도 리듬 동일 |
| **격자** | 12컬럼 관측 격자. A(좌) = 2~6컬럼, B(우) = 7~11, C(중앙) = 4~9. 세로 앵커 46~52%(현행). 중앙 비주얼(개구부·상승축·막)을 가리는 배치는 금지 | 03 §2.2 단일 초점·여백, §5.5.2 |
| **타입** | Cinzel lowercase 헤드라인(현행) / Pretendard 300 본문 / JetBrains Mono 계기(readout). 크기는 비트 간 동일, 명제 비트만 한 단계↑ | 03 §5.5.1 이중 언어 구조 |
| **색** | 잉크 `#e8ecec`. B5 에서만 프레임 휘도에 따라 `#1c2226` 으로 반전(f 매핑) | 화이트아웃 매치컷 |
| **계기 레이어** | 각 캡션 아래 모노 한 줄 `SHOT 02 · 00:03.2 · ●●○○○○○○○○○○` — 실제 영상 타임코드가 스크럽되고 12슬롯이 비트 진행에 따라 채워진다 | 인코더 리드아웃(12슬롯·시드)과 같은 언어 → 본편 UI 와 연결 고리 |
| **금지** | Glitch/RGB 분리, 그라디언트 텍스트, 스프링, 마키, 타이핑 효과음. 이모지·불릿 | 03 톤앤매너 |
| **reduced-motion** | f 매핑 변형은 전부 최종 상태로 고정, opacity 만 유지 | |

**변주가 허용되는 것**: ① 글자 스태거의 **순서·방향** ② 헤드라인의 **공간 변형**(분할·회전·원형 배치·중첩) ③ 본문의 **배치 관계**. 그 외는 건드리지 않는다.

## 2. 비트별 변주

강도 리듬: B0 中 → B1 **高** → B2 低 → B3 中高 → B4 **高** → B5 低. Unusual 레이아웃이 연속되지 않게 배치한다.

### B0 · *They Arrived* — 표면이 갈라진다 (0–4s, 0.8셀)

- **개념**: 첫 접촉. 매끈한 표면에 이음새가 생기고 개구부가 열린다.
- **레이아웃**: A(좌). **SectionWipe(seam)** — 헤드라인이 가로 1px 잉크 선(이음새)에서 위·아래로 **열리며** 드러난다. 개구부와 같은 물리.
- **키네틱**: f 0→0.35 에서 상반부 글자는 seam 위로, 하반부는 아래로 clip-path 마스크가 벌어짐(LettersPullUp 의 마스크를 seam 으로). 스태거 = 중앙 글자에서 양끝으로(균열이 퍼지듯). 본문은 f>0.45 부터 잉크 번짐 등장.
- **타이틀 셀 → B0 브리지**: 마스터 타이틀 `heptapod b` 가 셀을 떠날 때 letter-spacing 0.34em → 0.7em 으로 넓어지며 흩어진다("A R R I V A L" 와이드 트래킹의 소실).

```
┌──────────────────────────────────────┐
│                                      │
│   ─────── they arrived ───────       │  ← seam 이 열리며 글자가 위아래로 드러남
│   그들은 도착했고, 먼저 말을 건넸다.   │
│   SHOT 02 · 00:02.4 · ●○○○○○○○○○○○    │
│                                      │
│                 [개구부]              │
└──────────────────────────────────────┘
```

### B1 · *A Sentence, All at Once* — 원으로 그려지는 문장 (4–12s, 1.25셀)

- **개념**: 헵타포드 문장 = 시작도 끝도 없는 원. 한 번에 그려진다.
- **레이아웃**: B(우하). **CollageLayout 차용 — SVG `textPath` 원형 배치**. 헤드라인이 지름 ~34vh 링 위에 놓인다(로고그램 형태 인용). 링은 리프트·개구부(중앙)를 피해 우하 사분면.
- **키네틱**: 글자 스태거 **없음** — 전 글자가 동시에 blur→sharp("all at once" 의 문자적 구현, B0 의 순차와 대비). 링은 f 에 따라 0→90° 천천히 회전(리프트 상승과 동조), 하이라인 잉크 원(stroke-dashoffset)이 f 0→0.6 에서 그려진다. 역스크롤 = 역회전.
- **본문**: 링 왼쪽 안쪽 여백에 2줄, 링보다 늦게(f>0.5).
- **대안(낮은 강도)**: 링 대신 한 줄 헤드라인의 letter-spacing 이 0.3em→0.02em 으로 **응집**(흩어진 글자가 한 문장으로 모임).

```
┌──────────────────────────────────────┐
│                                      │
│                     a  s e n t e n   │
│  그들의 문장은 한 번에    c            │
│  그려진다. 시작도 끝도   e   ◯    e    │  ← 링 위 textPath, f 로 회전
│  없이, 하나의 원으로.     ,           │
│                     a l l  a t  o n  │
│      [리프트]     SHOT 02→03 · 00:07 │
└──────────────────────────────────────┘
```

### B2 · *No Before, No After* — 어둠 속 상승 (12–23s, 1.0셀)

- **개념**: 먼저와 나중이 같은 순간에. 프레임이 거의 검정(내부 어둠) → 화면이 비어 있으므로 **중앙·대형**이 허용되는 유일한 어두운 구간.
- **레이아웃**: C(중앙). Oversized Display(clamp 40~96px). **거울 대칭 배치** — 본문 두 줄을 헤드라인 **위·아래**에 나눠 놓는다("먼저" 위 / "나중" 아래). OverlappingStack 은 쓰지 않음(저강도 비트).
- **키네틱**: **양방향 스태거** — 글자가 양끝에서 중앙으로 동시에 드러난다(첫 글자도 마지막 글자도 먼저가 아니다). letter-spacing 0.25em→0.02em 으로 모임. 위·아래 본문은 정확히 같은 f 커브로 등장(어느 쪽도 먼저가 아님).
- **계기 레이어**: 타임코드가 이 비트에서만 **앞뒤로 동시에 카운트**되는 두 값(`00:12 ↑ · 00:23 ↓`)으로 표시 — 시간 방향의 상실.

```
┌──────────────────────────────────────┐
│          먼저와 나중이                 │
│                                      │
│   n o  b e f o r e ,  n o  a f t e r │  ← 양끝→중앙 스태거, 자간 응집
│                                      │
│          같은 순간에 존재한다.          │
│        00:12 ↑ · 00:23 ↓             │
└──────────────────────────────────────┘
```

### B3 · *Not Translation, but Encoding* — 명제 비트 (23–29s, 1.25셀)

- **개념**: 번역이 아니라 인코딩. 프로젝트의 정직한 명제. 위쪽 멀리 창백한 접촉면(작은 타깃)이 보이므로 텍스트는 **하단 중앙**.
- **레이아웃**: C(중앙) + **BrokenGrid 2컬럼** — 왼쪽 컬럼 `not translation`(흩어짐) / 오른쪽 컬럼 `but encoding`(결정화). 두 컬럼의 베이스라인을 의도적으로 한 줄 어긋나게(비대칭).
- **키네틱**: **스크럽 구동 TextScramble, 결정론**. `translation` 은 f 0.3→0.8 동안 글자가 로고그램풍 기호(`◦ ∘ ◌ ○`)로 흐트러지며 blur 로 사라진다. `encoding` 은 같은 구간에 기호에서 최종 글자로 **확정**된다. 스크램블 문자는 인코더와 같은 `xmur3 → sfc32` 시드(비트 id + 글자 index + f 를 24단계로 양자화)로 결정 → 같은 위치는 항상 같은 기호(플리커 없음, 역스크롤 가역). italic 900 강조는 `encoding` 에만.
- **계기 레이어**: `seed 0x7a3f91c2 · nfd 00 · slots ○○○○○○○○○○○○` — 아직 이름이 없어 슬롯이 비어 있다(인코더 예고).

```
┌──────────────────────────────────────┐
│                  ·  (접촉면, 멀리)     │
│                                      │
│                                      │
│   n∘t tr◌nsl○ti∘n                    │  ← 흩어짐(blur)
│                   ,  but  encoding   │  ← 결정화, italic 900, 베이스라인 어긋남
│   당신의 이름은 소리로 옮겨지지 않는다.  │
│   다만 하나의 사고로 응축된다.          │
│   seed 0x7a3f91c2 · slots ○○○○○○○○○○○○│
└──────────────────────────────────────┘
```

### B4 · *Perspective Inverts* — 중력 90° 전환 (29–35s, 0.9셀)

- **개념**: 벽이 바닥이 된다. 카메라의 중력 재정향.
- **레이아웃**: B(우). **DiagonalGrid 차용 — 세로쓰기 → 가로쓰기 회전**. 헤드라인이 처음엔 벽면 사인처럼 **세로(−90°, 아래→위 읽기)**로 서 있다가 f 0.2→0.8 에서 카메라 재정향과 함께 **0°** 로 눕는다. 회전 피벗은 텍스트 좌하단(판이 넘어지듯), 느린 스크럽 회전. 눕는 동안 letter-spacing·크기 불변.
- **키네틱**: 회전이 끝나야(f>0.75) 본문이 새 "바닥" 위에 등장하고, 그 아래 1px 잉크 선(바닥선)이 좌→우로 그려진다.
- **주의**: 회전 중간각에서 가독성이 떨어지므로 본문은 회전 전·중에는 절대 나타내지 않는다. 짧은 비트(0.9셀)라 회전 하나로 끝낸다.

```
   f = 0.1                      f = 0.9
┌──────────────────┐        ┌──────────────────┐
│               s  │        │                  │
│               t  │        │                  │
│               r  │        │   perspective    │
│               e  │   →    │   inverts        │
│               v  │        │   ────────────── │  ← 바닥선
│               n  │        │   벽이 바닥이 되는 │
│               i  │        │   곳에서, 관점이   │
└──────────────────┘        └──────────────────┘
```

### B5 · *Your Turn to Answer* — 막으로 걷기 → 화이트아웃 (35–47s, 1.2셀)

- **개념**: 그들의 문장이 완성되고 사라진다. 이제 당신 차례 → 인코더 입력으로 핸드오프.
- **레이아웃**: C(중앙). 저강도 — 레이아웃 변형 없음. 대신 **색 반전과 두 방향의 모션**이 서사.
- **키네틱**:
  - 헤드라인 `your turn to answer` 는 f 0.55→0.95 에서 안개 속으로 **흩어진다**(letter-spacing 0.02em→0.14em + blur + opacity↓) — "그들의 문장"의 소실.
  - 본문 마지막 문장 `이제, 당신이 답할 차례입니다.` 는 f 0.5→0.9 에서 **타자되듯**(Typewriter, 스크럽 구동 — 글자 수 = f 매핑) 잉크로 찍히고, 끝에 블록 커서 `▍` 가 남는다. 커서 깜빡임은 **유일한 시간 기반 모션**이며, 핸드오프에서 인코더 TextField 의 커서로 **매치컷**된다.
  - 텍스트 색은 f(=프레임 휘도 프록시)에 따라 `#e8ecec → #1c2226` 로 보간. 스크림도 같은 f 로 소거.
- **계기 레이어**: 슬롯 12개가 f 에 따라 모두 `●` 로 채워지고, 마지막에 `your turn ▍` 로 바뀐다.

```
   f = 0.4 (어두움)                 f = 0.95 (화이트아웃)
┌──────────────────────┐        ┌──────────────────────┐
│  your turn to answer │        │   y o u r  t u r n   │  ← 흩어짐(옅어짐)
│                      │   →    │                      │
│  그들의 문장이 완성되고 │        │  이제, 당신이 답할 차례입니다.▍│  ← 잉크, 타자, 커서 유지
│  빛이 차오른다.        │        │  ●●●●●●●●●●●●        │
└──────────────────────┘        └──────────────────────┘
```

## 3. 변주 매트릭스

| 비트 | 개념 | 배치 | 레이아웃 패턴(택소노미) | 키네틱 패턴(택소노미) | 스태거 순서 | 공간 변형 | 강도 |
|---|---|---|---|---|---|---|---|
| B0 | 첫 접촉·균열 | A | SectionWipe(seam) | LettersPullUp(마스크=seam) | 중앙→양끝 | 상하 분할 열림 | 中 |
| B1 | 원형 문장 | B | **CollageLayout**(textPath 링) | BlurInReveal 동시 | 없음(동시) | 링 회전 0→90° | **高** |
| B2 | 동시성 | C | Oversized + 거울 대칭 | CharacterStagger | 양끝→중앙 | 자간 응집 | 低 |
| B3 | 인코딩 명제 | C | **BrokenGrid** 2컬럼 | TextScramble(결정론·스크럽) | 흩어짐 vs 확정 | 베이스라인 어긋남 | 中高 |
| B4 | 중력 전환 | B | **DiagonalGrid**(세로→가로) | (회전) | — | −90°→0° 회전 | **高** |
| B5 | 응답·핸드오프 | C | 변형 없음 | Typewriter(스크럽) + 흩어짐 | 좌→우 | 색 반전 | 低 |

공통: 계기 레이어(모노 타임코드·12슬롯) 전 비트, 재질(blur 잉크) 전 비트, 이징 공통.

## 5. 구현 메모 (채택 후)

- 비트 로컬 f: `useTransform(progress, [clip.startNorm, clip.endNorm], [0, 1])` (MotionValue, 리렌더 없음). 글자 단위는 `motion.span` 에 `useTransform(f, …)` 을 개별 바인딩 — 6비트 × 30자 내외라 비용 무시 가능.
- 글자 분할: 공백 보존, 한글 본문은 글자 단위 대신 **어절 단위** 스태거(가독성).
- B1 링: `<svg><path id=ring d=원호/><text><textPath href=#ring>` + `rotate(f×90)`; 하이라인 원은 `stroke-dasharray/offset` 을 f 에 바인딩.
- B3 스크램블: 프로젝트 `encode.js` 의 `xmur3/sfc32` 재사용, f 를 24단계 양자화해 각 단계·글자별 기호 결정 → 가역·플리커 없음.
- B4 회전: `transformOrigin: 'left bottom'`, `rotate: useTransform(f, [0.2, 0.8], [-90, 0])`, `writing-mode` 대신 회전만 사용(폰트 메트릭 안정).
- B5 타자: 표시 글자 수 = `Math.round(f' × len)`; 커서는 CSS `steps(2)` 1s 깜빡임(reduced-motion 시 고정).
- 기존 캡션 컴포넌트(`BeatCaption`)를 `variant` 별 서브컴포넌트로 분기: `SeamCaption / RingCaption / MirrorCaption / ScrambleCaption / RotateCaption / TypeCaption`. 재질·타이밍은 공통 훅 `useInkReveal(f)` 로 강제.
